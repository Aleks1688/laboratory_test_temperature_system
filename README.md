# 🔬 Laboratory Test Temperature System

**Многоканальный контроллер для тестирования термопар в лабораторных условиях**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## 📋 Описание проекта

Устройство предназначено для **циклического измерения температуры до 10 термопар** (K-type) с передачей данных по MQTT. 

### Ключевая особенность — работа под высоким напряжением ⚡

Термопары устанавливаются **непосредственно на выводы LED и других компонентов**, которые находятся под потенциалом **400–500 В** (фаза сети 230 В AC или повышающий преобразователь LED-драйверов). Поэтому:

- **Оба провода каждой термопары (TC+ и TC-) коммутируются через DPDT реле**
- Полная **гальваноразвязка** между высоковольтной стороной термопар и низковольтной частью (ESP32)
- Питание датчика MAX31856 — от **изолированного DC-DC** (TMA-0505)
- SPI-сигнал проходит через **цифровой изолятор ISO7741**
- PCB спроектирована с учётом **creepage/clearance** для усиленной изоляции

## 🧩 Схема электрическая принципиальная

### Основные компоненты

| Компонент | Тип | Назначение | Кол-во |
|-----------|-----|------------|--------|
| **ESP32-J2** | Модуль Wi-Fi/Bluetooth SoC | Главный контроллер, WiFi, MQTT | 1 |
| **MAX31856** | АЦП термопар | Преобразование температура→цифра (SPI) | 1 |
| **ISO7741** | Цифровой изолятор | Гальваноразвязка SPI (4 канала) | 1 |
| **IM03GR** | Сигнальное реле DPDT | Коммутация TC+ и TC- каждого канала | **10** |
| **TMA-0505** | DC-DC изолированный | ±5V изолированное питание | 1 |
| **MIC5205-2.5** | LDO | 5V → 2.5V (референс MAX31856) | 1 |
| **AO3401A** | P-MOSFET | Ключ питания аналоговой части | 1 |
| **74HC595D** | Сдвиговый регистр | Управление 20 LED индикаторами | 1-2 |

### Драйвер реле (на канал)

Каждое реле IM03GR управляется через NPN-транзистор:

```
GPIO ESP32 ──[1kΩ]──┬── NPN (BC847 / MMBT3904)
                    │         │
                   GND       Collector ──[Катушка IM03GR]── +5VA_iso
                                          │
                                    [Flyback 1N4148W]
```

- Ток катушки IM03GR = **28 мА** (5V / 178Ω) → GPIO ESP32 не тянет напрямую!
- Flyback диод защищает транзистор от выброса ЭДС самоиндукции

## 💡 Индикация

У каждого разъёма термопары — **2 светодиода**:

| Цвет | Значение | Условие |
|------|----------|---------|
| 🟢 **Зелёный** | Канал активен, идёт замер | `currentRelay == thisChannel` |
| 🔴 **Красный** | Ошибка термопары | Fault бит от MAX31856 (обрыв, короткое замыкание) |
| ⚫ **Погашены** | Канал ждёт очереди | Default state |

LED управляются через **74HC595 сдвиговый регистр** (3 GPIO → 20 LED).

## ⚙️ Программная архитектура

### FreeRTOS задачи

```
┌─────────────┐    семафор     ┌──────────────────┐    семафор     ┌──────────┐
│  relayTask  │ ──────────────► │  tempSensorTask  │ ──────────────► │ mqttTask │
│  (приоритет 1)│               │  (приоритет 2)   │               │ (пrio 1) │
└─────────────┘                 └──────────────────┘                └──────────┘
      │                                 │                               │
      ▼                                 ▼                               ▼
 Циклическое                     Чтение MAX31856                  WiFi+MQTT
 переключение 10                 TC, CJ Temp, Fault               JSON publish
 реле с паузой                   Стабилизация 100ms               в топики:
 на разрядку 200ms                                                /temp/data
                                                                  /temp/status
```

### Логика работы цикла

1. **relayTask**: Все реле OFF → пауза 200мс (разрядка!) → включить следующее → семафор → ждать 5 сек
2. **tempSensorTask**: Ждёт семафор → пауза 100мс (стабилизация сигнала) → читать TC/CJ/fault → обновить LED → семафор MQTT
3. **mqttTask**: Держит соединение → получает данные → формирует JSON → публикует

### MQTT топики

| Топик | Формат | Периодичность |
|-------|--------|---------------|
| `temperature_system/data` | JSON: `{ch, temp_cj, fault, ts}` | Каждые ~5 сек (на канал) |
| `temperature_system/status` | `"online"` / `"offline"` (LWT) | При изменении |

### JSON формат данных

```json
{
  "channel": 3,
  "tc_temp": 245.67,
  "cj_temp": 32.15,
  "fault": 0,
  "timestamp": "2026-08-09T14:30:00"
}
```

Коды fault: `0`=OK, `1`=open circuit, `2`=short to GND, `3`=short to VCC.

## 🛠️ Сборка и прошивка

### Требования

- [PlatformIO Core](https://platformio.org/) (CLI или VS Code extension)
- [KiCad](https://www.kicad.org/) 8.x+ (для редактирования схемы/PCB)
- USB-UART адаптер для прошивки ESP32

### Прошивка

```bash
# Клонирование
git clone https://github.com/Aleks1688/laboratory_test_temperature_system.git
cd laboratory_test_temperature_system

# Создать secrets.h (см. ниже)
cp include/secrets.h.example include/secrets.h
# Отредактировать: WIFI_SSID, WIFI_PASSWORD, MQTT_SERVER_IP, etc.

# Сборка и прошивка
pio run -t upload --environment esp32dev

# Монитор последовательного порта
pio device monitor -b 115200
```

### Конфигурация WiFi/MQTT (`include/secrets.h`)

```cpp
#ifndef SECRETS_H
#define SECRETS_H

// WiFi
#define WIFI_SSID "YourNetworkName"
#define WIFI_PASSWORD "YourPassword"

// MQTT Broker
#define MQTT_SERVER_IP "192.168.x.x"
#define MQTT_SERVER_PORT 1883

#endif // SECRETS_H
```

> ⚠️ **`secrets.h` в `.gitignore`!** Не загружайте пароли в GitHub!

## 📐 Требования безопасности к PCB

Для рабочего напряжения **500В AC/DC** (Pollution Degree 2, лаборатория):

| Параметр | Минимум (IEC 60664-1) | Реализовано |
|----------|------------------------|-------------|
| Clearance (воздух между проводниками) | 2.5 мм | 3.0+ мм |
| Creepage (по поверхности PCB) | 2.5 мм | 4.0 мм + slotting |
| Между каналами термопар | 2.5 мм | **5.0 мм** (разные потенциалы!) |
| Изолированная ↔ Неизолированная зона | 4.0 мм | **6.0 мм + слот** |
| Конформное покрытие | Recommended | **Обязательно** |

### Slotting (увеличение creepage)

Между дорожками разных каналов и между зонами напряжения — **фрезерованные вырезы** в PCB:

```
  Канал 1 (TC)        ╔═══════╗        Канал 2 (TC)        ╔═══════╗
  [+] [-]             ║ ВЫРЕЗ ║        [+] [-]             ║ ВЫРЕЗ ║
    │                 ║ 2мм   ║          │                 ║ 2мм   ║
    └─────────────────╨───────╨──────────┴─────────────────╨───────╨───
                        ↑ creepage теперь через воздух (больше!)
```

## ⚠️ Предупреждения

### Электробезопасность ⚡⚡⚡
Это устройство работает с **опасным напряжением 400–500 В**. При неправильной сборке или использовании существует риск:
- **Поражения электрическим током**
- **Возгорания** при пробое изоляции
- **Повреждения измерительного оборудования**

**Всегда:**
- Соблюдайте creepage/clearance расстояния на PCB
- Используйте конформное покрытие высоковольтной зоны
- Проверяйте изоляцию мегомметром перед первым включением
- Работайте под присмотром квалифицированного персонала
