## 1. Выбор компонентов — Финализация

### 1.1 Реле: AXICOM IM03GR (TE 1-1462037-4)
| Параметр | Значение |
|----------|----------|
| Тип | Signal Relay, **DPDT (2 Form C / 2CO)**
| Катушка | 5V DC, **178Ω**, **28mA**, 140mW
| Контакты | PdRu+Au (золото), бифуркационные
| Номинал | **220VDC / 250VAC**, 2A max
| Изоляция контакт-катушка | **1800 Vrms** ✅
| Изоляция смежные контакты | 1000 Vrms
| Корпус | **SMT gull-wing**, 10×6×5.65mm
| Монтаж | Reflow до 260°C

**Использование DPDT:** POLE1 = TC+, POLE2 = TC- (оба провода коммутируются!)

### 1.2 Светодиоды индикации: Аксиальный Pilot LED 2×3×4.7mm
| Параметр | Значение |
|----------|----------|
| Тип | Axial "pilot light" LED, диффузный квадратный корпус |
| Размер | **2×3×4.7mm** (или 2×5×7mm вариант) |
| Монтаж | **Through-hole**, выводы через PCB, припаян снизу |
| Расположение | На верхней панели: отверстие Ø2-2.3mm, LED снизу, светит вверх |
| Цвета | 🟢 Зелёный (активный канал), 🔴 Красный (fault) |
| Ток | ~2-5мА (резистор 680Ω-1.5kΩ от 3.3V или 5V) |

**Всего:** 10 каналов × 2 цвета = **20 LED**

### 1.3 Драйвер реле: NPN транзистор
| Параметр | Значение |
|----------|----------|
| Тип | **BC847S** (dual NPN в SOT-23-6) или **MMBT3904** (SOT-23) |
| Ic max | 500mA (достаточно для 28мА катушки) |
| hFE | >100 (при Ic=10мА) → Ib < 0.3мА от GPIO |
| Резистор базы | **1kΩ** (Ib ≈ 2.6мА при 3.3V GPIO) |
| Flyback диод | **1N4148W** (SOD-123) или **LL4148** (MELF) |

**BC847S = 2 NPN в одном корпусе** → 5 штук на 10 реле вместо 10 отдельных!

### 1.4 Драйвер LED: 74HC595 сдвиговый регистр
| Параметр | Значение |
|----------|----------|
| Тип | **74HC595D** (SOIC-16) или **74HC595PW** (TSSOP-16) |
| Количество | **3 штуки** (3×8bit = 24 бита, используем 20) |
| Подключение | Каскадом: QH'→DS следующего |
| Управление | **3 GPIO**: DATA (SER), CLK (SRCLK), LATCH (RCLK) |
| Напряжение | 3.3V логика от ESP32 (HC-серия tolerant) |
| Ток вывода | ±6mA (хватит для LED через резистор) |

**Распределение бит 74HC595:**
```
Chip 1 (Q0-Q7):   CH1_ACTIVE, CH2_ACTIVE, CH3_ACTIVE, CH4_ACTIVE, CH5_ACTIVE, CH6_ACTIVE, CH7_ACTIVE, CH8_ACTIVE
Chip 2 (Q0-Q7):   CH9_ACTIVE, CH10_ACTIVE, CH1_FAULT, CH2_FAULT, CH3_FAULT, CH4_FAULT, CH5_FAULT, CH6_FAULT
Chip 3 (Q0-Q1):   CH7_FAULT, CH8_FAULT, CH9_FAULT, CH10_FAULT, [свободно x4]
```

## 2. GPIO Map — Финальное распределение

### ESP32-J2 доступные GPIO (исключая strapping/flash):
Используем только "безопасные" GPIO без странных побочек при старте:

| GPIO | Функция | Зона | Примечание |
|------|---------|------|------------|
| **SPI (через ISO7741):** ||||
| 5 | CS_MAX | Digital out | MAX31856 Chip Select |
| 18 | SPI_MOSI | Digital out | → ISO7741 INA → MAX31856 SDI |
| 19 | SPI_MISO | Digital in | MAX31856 SDO → ISO7741 OUTA → GPIO19 |
| 23 | SPI_SCK | Digital out | → ISO7741 INB → MAX31856 SCK |
| **Реле (драйверы NPN):** ||||
| 32 | RELAY_CH1 | Out | → R_base Q1 → IM03GR #1 катушка |
| 33 | RELAY_CH2 | Out | → IM03GR #2 |
| 25 | RELAY_CH3 | Out | → IM03GR #3 |
| 26 | RELAY_CH4 | Out | → IM03GR #4 |
| 27 | RELAY_CH5 | Out | → IM03GR #5 |
| 14 | RELAY_CH6 | Out | → IM03GR #6 |
| 22 | RELAY_CH7 | Out | → IM03GR #7 |
| 21 | RELAY_CH8 | Out | → IM03GR #8 |
| 17 | RELAY_CH9 | Out | → IM03GR #9 |
| 16 | RELAY_CH10 | Out | → IM03GR #10 |
| **LED драйвер (74HC595 ×3):** ||||
| 13 | LED_DATA (SER) | Out | 74HC595 serial data in |
| 12 | LED_CLK (SRCLK) | Out | Shift register clock |
| 15 | LED_LATCH (RCLK) | Out | Output latch strobe |
| **MAX31856 статус:** ||||
| 4 | DRDY | Digital in | Data Ready (опционально) |
| 2 | FAULT | Digital in | Fault output от MAX31856 |
| **Питание/управление:** ||||
| 13 | PWR_KEY | Out | AO3401A gate (включить изолированную часть) |

**Итого: 10 + 3 + 4 + 2 + 2 = 21 GPIO** ← ESP32-J2 потянет легко ✅

> ⚠️ GPIO 12 (HS2_DATA2) — избегаем! Влияет на flash voltage при старте.
> GPIO 0, 2, 5, 12 — strapping pins, используем осторожно (2 и 5 OK как обычные GPIO после boot).

## 3. Принципиальная схема — Описание по секциям

### Секция A: Питание (верх слева на схеме)
```
+5V ──┬── C1 0.1µF ── GND
      │
      ├── U15 MIC5205-2.5YM5 (IN=5V, OUT=2.5V)
      │    IN EN OUT BP GND
      │    │   │   │   │   │
      │    +5V HI 2.5VA C8 0.1µF GND
      │              │
      │              C6 0.1µF ── GND
      │
      └── U16 TMA-0505S (изолированный DC-DC)
           Vin+ Vin- Vout+ Vout-
           │     │     │      │
          +5V   GND  +5VA   -5VA (GND_A)
                    │       │
                   C7,C8  0.1µF each to GND_A
```
- **2.5VA** → референс MAX31856 (pin BIAS)
- **±5VA (GND_A)** → питание MAX31856 + катушки реле + ISO7741 сторона B

### Секция B: ESP32-J2 модуль (центр верх)
```
J4: ESP32-J2 разъём (все GPIO выведены)
├── 3V3 (от внутреннего LDO ESP32)
├── GND
├── EN, BOOT, RXD, TXD (для прошивки)
└── GPIO 2,4,5,12-33 (как в таблице выше)
```

### Секция C: Цифровой изолятор ISO7741 (справа верх)
```
U13: ISO7741DW (SOIC-16)
 Side A (LV):            Side B (HV_iso):
 INA  ← GPIO18 (MOSI)   OUTA → MAX SDI (pin 3)
 INB  ← GPIO23 (SCK)    OUTB → MAX SCK (pin 5)
 INC  ← MAX SDO (OUTC)  → GPIO19 (MISO)
 IND  ← (GND)           OUTD → (GND_A)
 VCC1 = 3V3             VCC2 = +5VA
 GND1 = GND             GND2 = GND_A
```

### Секция D: MAX31856 + защита входов (справа низ)
```
U14: MAX31856SS (TSSOP-20)
 Питание: AVDD=+5VA, DVDD=+5VA, GND=GND_A, BIAS=2.5VA
 SPI: SDI(3), SCK(5), SDO(6), CS(4)
 Аналоговые входы:
   T+ (pin 17) ── R27 100Ω ──┬── от реле (COM→NO полюс 1)
                              ├── C3 0.01µF ── GND_A
   T- (pin 18) ── R28 100Ω ──┬── от реле (COM→NO полюс 2)
                              ├── C4 0.01µF ── GND_A
 Защита:
   D1,D2: 1N4148 (T+ → AVDD, T+ → GND_A)
   D3,D4: 1N4148 (T- → AVDD, T- → GND_A)
 Статус:
   DRDY (pin 15) → GPIO4 (ESP32)
   FAULT (pin 14) → GPIO2 (ESP32)
```

### Секция E: 10× Реле IM03GR + драйверы (левая половина схемы)
```
На КАЖДЫЙ канал (пример CH1):

GPIO32 ──[R1 1kΩ]──┬── Q1a (BC847S half-A) NPN
                     │        │
                    GND      Collector ──┬── Coil_IM03GR_1 ── +5VA
                                           │
                                    [Flyback D1 1N4148W]
                                           │
                                          GND_A

IM03GR_1 (DPDT):
  Pole 1: COM1 ← TC+_CH1   NO1 ──[R_100]── MAX31856 T+
           NC1 ── открыт (никуда)
  Pole 2: COM2 ← TC-_CH1   NO2 ──[R_100]── MAX31856 T-
           NC2 ── открыт (никуда)

Повторить ×10!
```

**Размещение на PCB:** 2 ряда по 5 реле (левый и правый край платы)

### Секция F: Разъёмы термопар (нижний край PCB)
```
J2  ── TC1 (2-pin: +, -)
J3  ── TC2
...
J11 ── TC10

Тип разъёма: клеммник 5.08mm pitch (Phoenix-style) или штырьковой 2.54mm
Каждый разъём → напрямую на COM1/COM2 соответствующего IM03GR
```

### Секция G: LED индикация + 74HC595 (верхняя часть PCB)
```
U_LED1, U_LED2, U_LED3: 74HC595D (SOIC-16) — каскадом

Kаскад:
  GPIO13 (DATA) → U_LED1 DS (pin 14)
  GPIO12 (CLK)  → все SRCK (pin 11) параллельно
  GPIO15 (LAT)  → всех RCLK (pin 12) параллельно
  U_LED1 QH'(pin 9) → U_LED2 DS (pin 14)
  U_LED2 QH'(pin 9) → U_LED3 DS (pin 14)

Питание: VCC=3V3, GND=GND
OE' (pin 13) → GND (всегда включен)
SRCLR' (pin 10) → +3V3 (не сбрасывать)

LED (TH, 2×3×4.7mm, припаяны снизу, светят вверх):
  U_LED1 Q0 → [680Ω] → LED_CH1_GREEN (катод→GND)
  U_LED1 Q1 → [680Ω] → LED_CH2_GREEN
  ...
  U_LED2 Q2 → [680Ω] → LED_CH1_RED
  ...
  U_LED3 Q3 → [680Ω] → LED_CH10_RED
```

## 4. Конструкция PCB

### 4.1 Форм-фактор
- **Корпус:** DIN-рейка компактный (предположительно 4-6 TE модулей, ~72-108mm ширина)
- **Размеры PCB:** ориентировочно **100×80 мм** (точные размеры после выбора корпуса)
- **Слои:** 2 (Top + Bottom), толщина **1.6мм**
- **Материал:** FR-4 стандартный

### 4.2 Размещение по слоям

#### TOP LAYER (видимая сверху, лицевая панель):
```
┌──────────────────────────────────────────────────────┐
│  [TC1] ●○  [TC2] ●○  [TC3] ●○  [TC4] ●○  [TC5] ●○  │ ← Разъёмы термопар
│   ○G   ○R   ○G   ○R   ○G   ○R   ○G   ○R   ○G   ○R   │ ← LED отверстия (G=green, R=red)
│                                                      │
│  [TC6] ●○  [TC7] ●○  [TC8] ●○  [TC9] ●○  [TC10]●○  │
│   ○G   ○R   ○G   ○R   ○G   ○R   ○G   ○R   ○G   ○R   │
│                                                      │
│  ┌──────────────── ESP32 + ISO7741 + MAX31856 ─────┐ │
│  │  (центральная зона, безопасная)                  │ │
│  └──────────────────────────────────────────────────┘ │
│                                                      │
│  ┌──── 74HC595 ×3 + пассивки ──────────────────────┐ │
│  │                                                  │ │
│  └──────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────┘
```

#### BOTTOM LAYER (паяльная сторона, скрыта внутри корпуса):
```
┌──────────────────────────────────────────────────────┐
│  [IM03GR×5]         [IM03GR×5]                       │ ← Рле левый+правый ряд
│   Q1-Q5              Q6-Q10                           │
│   D1-D5 flyback      D6-D10 flyback                   │
│   R_base ×5          R_base ×5                        │
│                                                      │
│  [Транзисторы BC847S ×5]  [BC847S ×5]               │ ← Драйверы реле
│                                                      │
│  [Резисторы LED ×20]                                 │ ← Для 20 светодиодов
│                                                      │
│  [LED TH ×20 — припаяны здесь, выводы сквозные ↑↑↑]  │ ← Светят наверх!
│                                                      │
│  [TMA-0505] [MIC5205] [AO3401A]                      │ ← Питание
│  [Конденсаторы декаплинг]                             │
└──────────────────────────────────────────────────────┘
```

### 4.3 Отверстия для LED (сквозные, под установку TH-диодов)

```
  Вид сверху (Top layer):        Поперечное сечение:
                                    
  ┌───┐                            ════════ Top (маска)
  │ ○ │ ← Ø2.0-2.3mm отверстие      │       │
  └───┘                            │  LED  │ ← корпус 2×3mm
       ↑                           │ диф.  │
  LED светит                       ════════ Bottom (пятачки)
  через отверстие                  паяльник сюда ↑
  
  Диаметр отверстия: 2.0mm (под выводы 0.45-0.5mm + зазор)
  Размер пятачка: Ø3mm (annular ring)
  Расстояние между центрами LED: 5mm (минимум)
```

### 4.4 Зоны безопасности на PCB

```
╔══════════════════ HV ZONE (термопары 400-500V) ══════════════════╗
║                                                                   ║
║  J2-J11 (разъёмы TC)                                              ║
║       │                                                           ║
║       ▼                                                           ║

║       │                                                           ║
║  ═════╧══════════════════ ISOLATION BARRIER ═══════╧════════════  ║
║       │              (slotting + creepage ≥6mm)    │              ║
║  [R_100Ω] ×10                                        [R_100Ω] ×10 ║
║       │                                                           ║
║       ▼                                                           ║
║  [MAX31856] ← сидит на GND_A (изолированная земля)                ║
║       │                                                           ║
║  ═════╧════════════════ ISO7741 DIGITAL ISOLATION ═════╧════════  ║
║       │                        (5kVrms)              │              ║
║  [ESP32-J2] ← сидит на GND (земля контроллера)                     ║
║                                                                   ║

```

### 4.5 Slotting (вырезы для увеличения creepage)

Между HV зоной (реле/разъёмы TC) и LV зоной (MAX31856/ESP32):

```
  Top view:                    Cross-section:
                                
  [HV дорожки]                 ═══ Top copper ═══
       │                         │
  ╔═════╧══════╗                  │  AIR (clearance)
  ║  SLOT      ║  ← фреза 2mm wide, сквозной  │
  ║  (вырез)   ║                  │
  ╚═════╤══════╝                  ═══ Bottom copper ═══
       │                           
  [LV дорожки]                        
       
  Creepage теперь идёт: по top → вниз через стенку slot → по bottom → вверх
  Эффективная длина >> прямой по поверхности!
```

## 5. Порядок сборки

### 5.1 SMT компоненты (сначала нижнюю сторону!)
1. Напечатать пасту на Bottom layer
2. Смонтировать: IM03GR ×10, BC847S ×5, 1N4148W ×10, резисторы, конденсаторы, 74HC595 ×3, ISO7741, MIC5205, AO3401A
3. Reflow (или ручная пайка феном)
4. Перевернуть плату, смонтировать MAX31856 (если TSSOP на top)

### 5.2 Through-hole компоненты
1. Вставить LED ×20 снизу (ногами вверх!)
2. Вставить разъёмы термопар ×10 (сверху)
3. Вставить ESP32-J2 коннектор (сверху)
4. Паять TH components

### 5.3 Контроль
1. Визуальный осмотр
2. Проверка изоляции мегомметром (HV↔LV > 100MΩ при 500V)
3. Подать питание, проверить ток холостого хода
4. Прошить ESP32, протестировать MQTT
